# Sage — Teaching Assistant

A teaching assistant agent. Sage guides learners through material rather than
handing over answers: it asks the question that unblocks you, checks what you
actually understood, and adapts to where you are.

## Status

Scaffold created. Stack and scope still to be decided.

## Planned shape

- **Role** — a patient guide, not an answer machine
- **Behavior** — Socratic by default, direct when the learner is stuck
- **Memory** — tracks what a learner has covered and where they struggled
